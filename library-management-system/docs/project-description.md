\# Описание проекта



Данный проект является учебным примером репозитория для изучения Git и процессов ревьюирования программных продуктов.



\## Основные задачи

\- создание структуры репозитория;

\- работа с ветками;

\- создание pull request;

\- выполнение code review;

\- создание релизов и тегов;

\- настройка CI/CD.
