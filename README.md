\# Library Management System



Учебный проект по модулю ПМ.03 «Ревьюирование программных продуктов».



\## Цель проекта

Освоение практических навыков работы с Git, организации репозитория, работы с ветками, pull request, code review, тегами, релизами и CI/CD.



\## Структура проекта

\- docs — документация

\- src — исходный код

\- test — тесты

\- deploy — скрипты развёртывания

\- config — конфигурационные файлы

\- assets — статические ресурсы



\## Платформа

GitHub
